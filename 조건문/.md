# 조건문

```UIKit
import UIKit
// 다크 모드 여부

var isDarkMode  == true
if isDarkMode {
  print("다크모드 입니다.")
}else{
  print("다크모드 입니다.")
}
```
isDarkMode가 
* true 일때 : "다크 모드 입니다"
* true가 아닐때 : "다크 모드가 아닙니다."
